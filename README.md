## 🐶 About Me

> 낮에는 **배터리(이차전지) 연구자**, 밤에는 **AI로 귀찮은 일을 자동화하는 사람**이에요.
> 코딩은 늦게 시작했지만, AI와 함께라면 "생각한 걸 만들어 보는" 게 제일 재밌어요.

- 🔋 **본업**: 이차전지·전고체전지 연구, 실험 데이터 정리와 분석
- 🤖 **취미이자 특기**: AI 에이전트로 일을 통째로 자동화하기
- ✍️ **운영 중**: 경제·배터리·AI 소식을 다루는 [블로그](https://blog.naver.com/dh013208) (매일 자동 발행 파이프라인)
- 📚 **공부 중**: AI 학습 로드맵을 직접 정리해 남에게 가르치는 교재로 만드는 중
- 🎬 **요즘 빠진 것**: 직접 찍은 영상을 AI로 편집하기

## 🛠️ What I Build

| | 프로젝트 | 한 줄 소개 |
|:-:|---|---|
| 📰 | **Blog Auto Pilot** | 뉴스 수집 → AI 글쓰기 → 팩트체크 → 이미지 → 블로그 발행까지 사람 손 없이 |
| 🔋 | **Battery Data Platform** | 분석 장비 파일을 한곳에 모아 자동 차트·이상치 검출까지 하는 연구 데이터 플랫폼 |
| 📄 | **Battery Paper RAG** | 배터리 논문을 모아 읽고 질문에 답해 주는 논문 비서 |
| 🎙️ | **EchoLog** | 회의를 녹음하면 받아쓰고 요약까지 해 주는 회의록 앱 |
| 🎞️ | **Video Editor** | 캡컷 Pro 기능을 오픈소스로 직접 만든 영상 편집기 |
| 🃏 | **Card News Maker** | 블로그 글을 인스타 카드뉴스로 자동 변환 |
